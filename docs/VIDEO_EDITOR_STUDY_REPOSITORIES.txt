Updated: 2026-11-15
Project: https://github.com/anneshabiswaas22-collab/advance-video-edior

PURPOSE: A consolidated reference inventory of editor frameworks, media processing
libraries, AI models and professional post-production tooling discussed for the
CapCut + DaVinci Resolve + Adobe Premiere-class video-editor goal.

IMPORTANT: These are STUDY / EVALUATION REFERENCES, not a list of approved
dependencies. Public source does not imply commercial redistribution clearance.
Do not bulk-clone or merge entire editors into the product. Keep ONE canonical
project/timeline/rendering model. Audit source, dependency, codec, font, model-
weight and media-asset licenses separately; prioritize reuse before rebuilding.

CURRENT FOUNDATION:
- OpenReel has been imported at editor/ under a pinned source revision.
- FreeCut has been cloned/tested separately as a comparative candidate.
- Existing candidate revisions: docs/evidence/supporting-source-inventory.md

IMPLEMENTATION / CODEX RULES
============================================================================
1. Evaluate primary foundation on actual importing, scrubbing, save/reopen, export.
2. Reuse existing editor capabilities before writing another feature.
3. Integrate specialized libraries via adapters, not parallel render engines.
4. Record exact source commits, license findings and reproducible test evidence.
5. Do not silently invoke paid inference or download noncommercial model weights.
6. Verify actual exported video frames, audio timing, codecs, duration, GPU speed.
7. Windows and 4K claims require matching native/hardware validation.
8. Refer to AGENTS.md, docs/CODEX_REVIEW_QUEUE.md and Issue #6 before new work.
